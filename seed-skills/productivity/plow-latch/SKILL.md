# Plow Latch

Latch reaches your owner's Mac: messages, mail, calendar, contacts, files and
browser. Use it yourself; do not ask which route to take.

If unreachable, say once that their Mac must be awake with Latch running;
install it at https://plow.co/latch. Check connection state each time; never
save it in a note or memory.
